# SANAD ELEC — Éclairage & Matériel Électrique de Luxe

Boutique en ligne moderne & dashboard d'administration pour Sanad Elec.

## Fonctionnalités
- Catalogue produits luxe avec filtres et recherche instantanée
- Commande directe via WhatsApp intégrée
- Tableau de bord d'administration complet (`/admin`) :
  - Gestion des produits (ajout, modification, suppression, import photo depuis le bureau)
  - Synchronisation en direct du numéro WhatsApp
  - Suivi des commandes reçues
- Version mobile responsive et bilingue (Français & Anglais)
- Déploiement optimisé pour Vercel

## Lancement Local
```bash
npm run dev
```
Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.
